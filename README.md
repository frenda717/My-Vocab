# 🍬 百詞斬單詞本

雙擊 `index.html` 就能開（不需要架伺服器）。`index.html` 和 `words.js` **必須放在同一個資料夾**。

- **77 個單字**，擷取自 `..\百詞斬\` 裡的 **128 張截圖**
- 資料 **100% 來自截圖**：截圖沒拍到的音標／釋義／詞根詞綴一律留空，不從字典補
- 每張卡片底部都列出「來源截圖」檔名，可以回頭核對

---

## 怎麼用

| 動作 | 說明 |
|---|---|
| **點英文單字** | 展開／收合該卡的所有中文 |
| **點色卡（近義／形近／反義）** | 只顯示那一個詞的中文 |
| **👁 全部顯示中文** | 一次把所有卡片攤開 |
| **⭐ 只看重點** | 只留下你在截圖上用黃筆／紅圈綠圈標註過的字 |
| **✅ 隱藏已掌握** | 配合卡片右上角的 ○ / 🏅 使用 |
| **搜尋框** | 中英通吃。`glimmer`、`希望`、`嚴格`、`-ly`、`峽谷` 都能搜到 |
| **排序** | A→Z / Z→A / 加入順序 / 語義分組 / 搭配最多 |
| **記憶池** | 把字卡**拖進**右側池子（或點卡片的 ＋）；池內可拖曳排序 |
| **💾 儲存這組記憶詞** | 存成具名記憶組，之後可從下拉選單載回來 |
| **📄 匯出 PDF** | 開啟列印視窗，印表機選「**另存為 PDF**」即可 |

進度（已掌握、記憶池、記憶組、上次的篩選設定）存在瀏覽器的 localStorage，**更新 `words.js` 不會弄丟**。

## 以後新增單字

有新截圖時，最省事的做法是**把新截圖丟進 `..\百詞斬\`，然後跟 Claude 說**：

> 幫我把 `C:\Users\frend\Downloads\百詞斬\` 裡的新截圖，照 `詞庫\words.js` 現有的格式加進去。一樣只用截圖內容，黃筆／紅圈綠圈標到的標成 `hl: true`。

也可以自己手動加：打開 `words.js`，在陣列**最後**貼一個物件，存檔後重新整理網頁即可。

### 欄位對照表

```js
{
  "id": "glimmer",                  // 唯一鍵，小寫單字
  "word": "glimmer",
  "phonetic": { "us": "", "uk": "" },      // 截圖沒拍到就 ""
  "pos": "v",                       // n / v / adj / adv / other → 決定放哪個分頁
  "posSure": false,                 // false = 截圖沒明寫詞性，卡片會顯示灰色「?」
  "senses": [ { "pos": "n.", "zh": "微光；一絲", "hl": false } ],
  "roots": [ { "part": "liter", "type": "词根", "zh": "字母" } ],   // 詞根詞綴
  "rootSummary": "与认识字母相关的能力=读写能力",
  "mnemonic": "",                   // 小斩助记
  "note": "在雅思剑9~剑20中出现2次",
  "starred": false,                 // 你在 App 裡標了藍星星
  "derivatives": [ { "en": "exhilarating", "pos": "adj.", "zh": "令人高兴的" } ],
  "examples": [ { "en": "…", "zh": "…", "src": "影集名", "hl": false } ],
  "collocations": {
    "basic":   [ { "en": "glimmer of hope", "zh": "一线希望", "hl": false } ],
    "context": [ { "en": "…", "zh": "…", "hl": false } ]
  },
  "synonyms":    [ { "en": "eloquence", "zh": "", "hl": true } ],   // 🟢 近義詞
  "similar":     [ { "en": "vigorous",  "zh": "强有力的", "hl": false } ], // 🔵 形近詞
  "antonyms":    [ { "en": "dullness",  "zh": "", "hl": false } ],  // 🩷 反義詞
  "substitutes": [ {                                                // 🟣 同義替換
    "en": "collapse", "pos": "v.", "zh": "倒塌；崩溃",
    "note": "情感负面，强调突然且彻底地失败或倒下。",
    "ex": { "en": "collapse under the pressure", "zh": "在压力下崩溃" },
    "hl": false
  } ],
  "group": "光·閃耀·明亮",           // 語義分組（「語義分組」排序模式會用到）
  "sources": [ "IMG_3270.PNG" ]     // 來源截圖檔名
}
```

**規則**

- 空欄位一律留 `""` 或 `[]` — 版面會自動跳過，卡片不會出現空殼區塊。
- `hl: true` 表示這一行是你手動標註過的重點（黃色螢光筆、紅圈、綠圈），會加上 ⭐ 並被「只看重點」篩到。
- `group` 可以沿用現有的 14 個標籤，或自己開新的（同名的會自動聚在一起）：
  光·閃耀·明亮／言辭·表達·聲音／嚴格·秩序·監督／愉悅·滿足·寵愛／煩惱·不適·絕望／
  地形·自然·地質／破壞·衝突·犯罪／繁榮·復甦·成長／人物·身分·群體／移動·轉向·時間／
  數量·評估·範圍／邊緣·細節·觸感／飲食·物品·展示／限制·封閉·託付
- 截圖是簡體，資料就照原樣保留簡體；介面文字是繁體。

## 詞性歸類的一點說明

很多截圖是往下捲動的畫面，標題區的詞性被切掉了。這種情況下的歸類，是依截圖裡**可見的搭配用法**判斷的（例如 `enormously popular` → adv.、`cosset oneself` → v.），並在卡片上標一個灰色 `?` 提醒你這欄是推斷的，不是截圖明寫的。
