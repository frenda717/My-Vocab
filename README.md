# 🍬 百詞斬單詞本

雙擊 `index.html` 就能開（不需要架伺服器）。`index.html` 和 `words.js` **必須放在同一個資料夾**。

- **254 個單字**，全部繁體中文
- 音標／釋義／詞根詞綴以截圖內容為準；色卡（近義／形近／反義）的中文若截圖沒給，補上通用釋義，讓每個色卡點下去都看得到意思

### 手寫標記怎麼被讀進來

| 標記 | 處理方式 |
|---|---|
| 黃筆／紅圈／綠圈 | 該行標成 `hl: true`，會被「⭐ 只看重點」篩到 |
| **紅線劃掉** | 該詞（或該行形近詞／同義替換）**不錄入** |
| **綠色 S 形圈住整張卡** | 主詞太簡單，改錄卡片裡的**同義替換詞**，例句也換成該同義詞；被替換掉的原詞用**洋紅色**標在卡片上 |

目前用綠圈替換掉的有 5 組：`replenish`←restock、`servitude`←slavery、`custodian`←guardian、`industrious`←diligent、`rearward`←backward。

### Part 分批

單字量會一直長，頂端有 **Part 選單**可以只看某一批。目前 254 個詞全部是 **Part 1**；Part 2、Part 3 是空的，之後新增時把 `part` 填 2 或 3 就會歸到那一批。

## 怎麼用

| 動作 | 說明 |
|---|---|
| **點英文單字** | 展開／收合該卡的所有中文 |
| **點色卡（近義／形近／反義）** | 只顯示那一個詞的中文 |
| **👁 全部顯示中文** | 一次把所有卡片攤開 |
| **⭐ 只看重點** | 只留下用黃筆／紅圈綠圈標註過的字 |
| **✅ 隱藏已掌握** | 配合卡片右上角的 ○ / 🏅 使用 |
| **搜尋框** | 中英通吃。`glimmer`、`希望`、`嚴格`、`-ly`、`峽谷` 都能搜到 |
| **📚 Part 選單** | 只看某一批單字（Part 1／2／3） |
| **排序** | A→Z / Z→A / 加入順序 / 語義分組 / 搭配最多 |
| **記憶池** | 把字卡**拖進**右側池子（或點卡片的 ＋）；池內可拖曳排序 |
| **💾 儲存這組記憶詞** | 存成具名記憶組，之後可從下拉選單載回來 |
| **📄 匯出 PDF** | 開啟列印視窗，印表機選「**另存為 PDF**」即可 |

進度（已掌握、記憶池、記憶組、上次的篩選設定）存在瀏覽器的 localStorage，**更新 `words.js` 不會弄丟**。

## 以後新增單字

有新截圖時，最省事的做法是**把新截圖丟進 `..\百詞斬\`，然後跟 Claude 說**：

> 幫我把 `C:\Users\frend\Downloads\百詞斬\` 裡的新截圖，照 `詞庫\words.js` 現有的格式加進去，`part` 填 2。中文用繁體，色卡的中文都要填。黃筆／紅圈綠圈標到的標成 `hl: true`；紅線劃掉的不錄；綠色 S 形圈住的改錄同義替換詞，並把被替換的原詞放進 `replaced`。

也可以自己手動加：打開 `words.js`，在陣列**最後**貼一個物件，存檔後重新整理網頁即可。

### 欄位對照表

```js
{
  "id": "glimmer",                  // 唯一鍵，小寫單字
  "word": "glimmer",
  "phonetic": { "us": "", "uk": "" },      // 截圖沒拍到就 ""
  "pos": "v",                       // n / v / adj / adv / other → 決定放哪個分頁
  "posSure": false,                 // false = 詞性是依搭配用法推斷的（卡片上不另外標示）
  "senses": [ { "pos": "n.", "zh": "微光；一絲", "hl": false } ],
  "roots": [ { "part": "liter", "type": "詞根", "zh": "字母" } ],   // 詞根詞綴
  "rootSummary": "與認識字母相關的能力=讀寫能力",
  "mnemonic": "",                   // 小斬助記
  "note": "",                       // 只放自己的學習筆記，不放考頻／App 狀態
  "starred": false,                 // 標記為重點
  "derivatives": [ { "en": "exhilarating", "pos": "adj.", "zh": "令人高興的" } ],
  "examples": [ { "en": "…", "zh": "…", "src": "影集名", "hl": false } ],
  "collocations": {
    "basic":   [ { "en": "glimmer of hope", "zh": "一線希望", "hl": false } ],
    "context": [ { "en": "…", "zh": "…", "hl": false } ]
  },
  "synonyms":    [ { "en": "eloquence", "zh": "雄辯，口才", "hl": true } ],   // 🟢 近義詞
  "similar":     [ { "en": "vigorous",  "zh": "強有力的", "hl": false } ],    // 🔵 形近詞
  "antonyms":    [ { "en": "dullness",  "zh": "遲鈍；乏味", "hl": false } ],  // 🩷 反義詞
  "substitutes": [ {                                                // 🟣 同義替換
    "en": "collapse", "pos": "v.", "zh": "倒塌；崩潰",
    "note": "情感負面，強調突然且徹底地失敗或倒下。",
    "ex": { "en": "collapse under the pressure", "zh": "在壓力下崩潰" },
    "hl": false
  } ],
  "replaced": null,                 // 🩷 若這個詞是替換掉太簡單的原詞而收錄：
                                    //    { "en": "guardian", "zh": "監護人；守護者" }
  "group": "光·閃耀·明亮",           // 語義分組（「語義分組」排序模式會用到）
  "part": 1                         // 分批標籤，頂端 Part 選單用
}
```

**規則**

- 空欄位一律留 `""` 或 `[]` — 版面會自動跳過，卡片不會出現空殼區塊。
- `hl: true` 表示這一行是你手動標註過的重點（黃色螢光筆、紅圈、綠圈），會加上 ⭐ 並被「只看重點」篩到。
- `group` 可以沿用現有的 26 個標籤，或自己開新的（同名的會自動聚在一起）：
  光·閃耀·明亮／言辭·表達·聲音／嚴格·秩序·監督／愉悅·滿足·寵愛／煩惱·不適·絕望／
  地形·自然·地質／破壞·衝突·犯罪／繁榮·復甦·成長／人物·身分·群體／移動·轉向·時間／
  數量·評估·範圍／邊緣·細節·觸感／飲食·物品·展示／限制·封閉·託付／水·液體·流動／
  任務·事業·承諾／衣著·外觀·風格／醫療·健康·防護／法律·訴訟·裁決／方位·形狀·結構／
  認知·知識·學習／動物·生態·生物／交通·運輸·船隻／寧靜·平和·安穩／誘因·動機·刺激／
  商業·經濟·貿易
- **中文一律繁體**（截圖是簡體，錄入時轉成繁體）。
- 每個色卡的 `zh` 都要填，否則點下去不會顯示中文。
- `part` 不填時視為 1。

## 詞性歸類的一點說明

有些詞的來源畫面沒拍到詞性，這種情況下的歸類是依**可見的搭配用法**判斷的（例如 `enormously popular` → adv.、`cosset oneself` → v.），資料裡以 `posSure: false` 記錄，卡片上不另外標示。
